# InfraSnap privacy and support

Public static pages for InfraSnap. This repository contains no application source code, credentials, or private App Store review information.

## Free GitHub Pages hosting

Create `dtce-design/InfraSnap-Support-Page` as a **public** repository, then upload these files to the root of its `main` branch.

In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/ (root)**, then save.

After deployment succeeds:

- Privacy: https://dtce-design.github.io/InfraSnap-Support-Page/privacy.html
- Support: https://dtce-design.github.io/InfraSnap-Support-Page/support.html

These addresses are planned URLs until deployment has completed.
