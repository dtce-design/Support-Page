Requirements and installation

The app requires iOS 16 or later, an iPhone with enrolled Face ID, and a compatible encrypted mobile signing-key export from an authorized Windows DTCE administrator. Installation is available through the download link supplied by DTCE when an approved release is available.

Unlisted App Store distribution uses a direct download link rather than App Store search. Anyone with the link may download the app; generating working approvals still requires a matching administrator key and Face ID.

Importing your key

  1. Keep a safe backup of your original encrypted mobile export.
  2. Open the app and select Import your mobile key.
  3. Choose the .dtcekey file in Files. The Windows .dat file is not the mobile export format.
  4. Enter the export password and complete the Face ID protection steps shown in the app.

After import, the app saves the key in the iPhone Keychain. Reopening or returning from the background requires Face ID. A normal restart does not require a fresh key import.

Generating approvals

For normal access, paste the complete Windows request code and select the programs to approve. Normal codes last eight hours from generation. The Windows User app requires a new approval after it is fully closed and restarted; closing a worksheet while the main app remains open retains the current session.

Certification mode creates a thirty-day credential for the exact Windows version entered. Keep generated credentials private and share approvals only with their intended recipient.

Face ID or import problems

Confirm Face ID is enrolled and available in iPhone Settings. If Face ID enrollment changed, the saved key may no longer unlock. With your original encrypted export safely backed up, use Remove saved key and import the export again. Import also requires the correct password and a key matching the Windows DTCE Tool Kit.

Requesting help

Include your iPhone model, iOS version, app version/build and the error message. If attaching a screenshot, hide request codes, approval codes and other private information. Never send a signing key, key export or password to support.
